# Purpose

Create or improve content so it is clear, credible, scannable, and aligned to the reader's goal.

## Use when

- The task is writing or rewriting an article, section, landing page, or brief.
- The main risk is weak structure, clarity, or usefulness.
- You need readable content with a strong outline and trust signals.

## Avoid when

- The main task is keyword research or SERP analysis.
- The main task is CMS entry or publishing QA.
- The output is code, not prose.

## Required inputs

- Audience.
- Objective.
- Topic or source material.
- Desired format or length if constrained.

## Workflow

1. Clarify reader, outcome, and content type.
2. Build a lean outline before drafting.
3. Write for clarity first, then add proof, examples, and trust signals.
4. Tighten headings, intros, transitions, and calls to action.
5. Remove filler and repetition.

## Expected outputs

- Clean outline or draft.
- Reader-centered headings.
- Clear takeaways or CTA.
- Notes on assumptions or missing source evidence.

## Checks before done

- Each section has a job.
- The draft answers the likely reader question quickly.
- Claims that need evidence are supported or labeled.

## Common failure modes

- Writing around the point instead of answering it.
- Repeating ideas across sections.
- Using generic trust language without concrete signals.
