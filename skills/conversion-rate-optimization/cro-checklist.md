Summary: Fast checklist for designing and validating SaaS CRO tests.

# CRO Checklist

## Pre-test

- Confirm conversion event definition.
- Verify analytics and event tracking.
- Record baseline by source and device.
- Document hypothesis and expected direction.

## Page and flow friction checks

- Message matches visitor intent.
- Hero section explains value in one read.
- Proof elements support claims.
- CTA is singular and specific.
- Form fields are minimal and justified.
- Mobile flow is complete and readable.

## Experiment quality

- One main change group per test.
- Primary metric and guardrail metrics defined.
- Runtime and minimum sample thresholds set.

## Post-test decision

- Keep if primary metric improves and guardrails hold.
- Iterate if signal is positive but weak confidence.
- Revert if performance drops or quality declines.
