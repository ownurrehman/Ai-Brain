# Shipping Features

## Delivery rules

- Prefer the smallest complete implementation over a wide partial one.
- Reuse existing patterns before introducing a new abstraction.
- Keep the user-visible outcome in view while coding.
- Run the narrowest meaningful verification before stopping.

## Completion test

The feature is done when the requested behavior works, the change is understandable, and known risks are named.
