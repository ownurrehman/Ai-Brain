# Rank Ray — SEO services

**Agency:** [Rank Ray](https://www.rankray.com) — SEO as a service line (audits, roadmaps, implementation guidance, reporting).

## Use when

- A **client SEO** engagement: audit, keyword / intent work, technical fixes, on-page, schema, local, or ongoing SEO program.
- You need **prioritized recommendations** tied to business outcomes (leads, revenue proxies, not only rankings).
- Work touches **WordPress or RankRay-HQ SEO surfaces** as delivery channels—still use this skill for SEO intent; use **`../wordpress-publisher/SKILL.md`** or **`../rankray-seo-ui/SKILL.md`** for CMS/UI execution details.

## Avoid when

- No search goal—pure brand storytelling → **`../content-writing/SKILL.md`**.
- Only **RankRay product UI** patterns without client SEO strategy → **`../rankray-seo-ui/SKILL.md`**.

## Rank Ray delivery norms

- One **primary intent** per page; cluster keywords deliberately—avoid infinite thin pages.
- **Technical + on-page + content** recommendations should be ordered by impact × effort.
- Mark **assumptions** when crawl or GSC/live data is missing.
- Align with **E-E-A-T** and client vertical truthfulness (especially YMYL-adjacent).

## Workflow (summary)

1. Define scope: audit vs roadmap vs implementation support vs reporting.
2. Baseline: tech crawl signals, indexation, key templates, priority URLs.
3. Intent map: queries → pages → content gaps → internal linking.
4. Deliver prioritized backlog with owners and measurement.
