# Debugging

## Heuristics

- Reproduce before theorizing when possible.
- Narrow the failing path before changing code.
- Prefer one confirmed cause over many unproven suspicions.
- Capture the evidence that changed your mind.

## Good debug output

- Symptom.
- Reproduction path.
- Root cause.
- Fix.
- Verification result.
