# ✍️ RankRay Semantic SEO & AEO Content Writing

> **Standard operating procedure for high-ranking, entity-dense SEO and AEO articles.**

---

## 🎯 1. Core Editorial Standards
- **Word Count:** 2,000+ words for pillar articles; 1,200–1,800 words for supporting cluster spokes.
- **Answer-First (AEO) Formatting:** The first paragraph directly below each `<h2>` must answer the search query immediately in 2–3 concise sentences before expanding into analysis.
- **Zero Em-Dashes:** Never use em-dashes (`—`). Use crisp, well-punctuated sentences.
- **Zero AI Fluff:** Never use generic intro filler (*"In today's fast-paced digital world..."*, *"It's no secret that..."*, *"When it comes to..."*).

---

## 🏛️ 2. Article Structure Template

```markdown
# [Main Target Keyword with Compelling Benefit Hook]

[Direct, authoritative summary answering the core query and setting up the guide (80-120 words).]

## [Core Problem/Concept Breakdown]
[Direct answer paragraph: 2-3 sentences providing immediate clarity.]
[In-depth contextual explanation.]

## [Step-by-Step Actionable Framework / Comparison Table]
| Key Factor | Standard Approach | Recommended Solution |
|---|---|---|
| Factor A | ... | ... |
| Factor B | ... | ... |

## [Common Pitfalls & How to Avoid Them]
- **Mistake 1:** [Explanation + Fix]
- **Mistake 2:** [Explanation + Fix]

## [Key Takeaways / Next Steps]
[Summary with contextual CTA pointing to relevant service page.]
```

---

## 🔗 3. Internal Linking Rules
- Minimum **3–5 internal links** per 2,000 words.
- Priority: Link to transactional service pages first, then relevant pillar hubs.
- Anchor text must be descriptive and semantic (avoid "click here" or raw URLs).
