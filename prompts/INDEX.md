## 💡 How to Use These Prompts

1. **Before Running in Cursor / Claude:**
   * Open the target prompt template.
   * Fill out the `[Input Parameters]` block at the top with your specific project details, URLs, or keywords.
2. **For Site-Specific Deployments (e.g. Justccell):**
   * Prepend the **Critical Master Directive** before your task instructions so the coding agent strictly adheres to architecture, Hostinger MCP access, and non-negotiables.
3. **Continuous Sync Requirement:**
   * Every execution that modifies code, content, or CMS settings must update `features-code-map.md`, `docs/STATUS.md`, and `docs/BUILD-LOG.md` in the exact same turn.
