# Blog Post Templates for Enigma

## Template 1: How-To Guide

```
TITLE Formula: How to [Achieve Result] in [Timeframe] (Without [Common Pain])

META: Learn how to [achieve result] in [timeframe]. This step-by-step guide shows you [benefit]. [Brand]

STRUCTURE:
H1: How to [Achieve Result]

Introduction (Hook → Problem → Promise)

H2: What You'll Need
H2: Step 1: [First Action]
H2: Step 2: [Second Action]
...
H2: Step X: [Final Action]
H2: Pro Tips for Better Results
H2: Common Mistakes to Avoid
H2: FAQ
H2: Conclusion + CTA

INTERNAL LINKS:
- Link to: Related tool/resource
- Link to: Service/product that solves this
```

## Template Selection Guide

| Content Goal | Best Template | Word Count |
|--------------|---------------|------------|
| Rank for "how to" queries | How-To Guide | 1500-2500 |
| Drive product comparisons | Comparison Post | 2000-3500 |
| Build authority | Pillar/Definition | 3000-5000 |
| Social shares | Listicle | 1500-2500 |
| Convert leads | Case Study | 1200-2000 |
