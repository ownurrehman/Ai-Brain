# Ai Brain

Central knowledge vault and agency intelligence hub for all AI agents and Obsidian.

## Quick start

1. Read [`INDEX.md`](INDEX.md) — navigation and directory map
2. Read [`docs/ENV.md`](docs/ENV.md) — where credentials live (names only)
3. Read `master-env.env` — actual secrets (gitignored)
4. Read the site or project `mastersheet.md` for the job you are on
5. Optional: [`prompts/MASTER-SYSTEM-BOOTSTRAP.md`](prompts/MASTER-SYSTEM-BOOTSTRAP.md)

## Folders

| Path | What it is |
|------|------------|
| `websites/` | Client and marketing **websites** strategy & profiles (rankray.com, tonicphysio.com, …) |
| `projects/` | Internal apps, bots, and project documentation |
| `agents/` | Per-agent memory (`hermes/`, `chronos/`, `alpha/`, `enigma/`, `emilia/`, `scout/`, `nemo/`) |
| `credentials/` | Secrets (OAuth, per-site env). Gitignored. |
| `rules/` | Content, SEO, and access standards |
| `skills/` | Agent skills library (shared across Antigravity & Hermes) |
| `prompts/` | Master prompt + templates |
| `system/` | Multi-agent autonomous flows (CrewAI), backups, and system runtimes |
| `reports/` | Generated strategic plans and agent swarm deliverables |
