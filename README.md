# AI Brain

Central knowledge base for all AI agents. Contains rules, skills, project data, and credentials.

## Quick Start

1. Read `INDEX.md` for navigation
2. Read `master-env.env` for credentials
3. Read `prompts/MASTER-SYSTEM-BOOTSTRAP.md` for the master prompt

## Folders

- `projects/` — Client site data (mastersheets, content plans, registries)
- `rules/` — Content quality rules, rate limiting, voice guides
- `prompts/` — Master prompt + task templates
- `skills/` — Skill library (SEO, CRO, publishing, development)
- `openclaw/` — OpenClaw agent workspace
- `hermes/` — Hermes agent workspace
