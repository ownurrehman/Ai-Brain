# UI UX Patterns

## Prefer

- One clear primary action per surface.
- Visible system status for loading, success, and failure.
- Progressive disclosure for advanced controls.
- Copy that explains outcome, not internal mechanics.

## Watch for

- Dense layouts with no hierarchy.
- Hidden destructive actions.
- Error states that do not tell the user what to do next.
