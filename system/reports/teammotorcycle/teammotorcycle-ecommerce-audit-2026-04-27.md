## Key SEO Checks

### Good
- ✅ Sitemap auto-generated by Shopify, all sections present
- ✅ Products have images in sitemap with alt/title/caption
- ✅ Collections actively maintained and fresh
- ✅ Daily product updates reflected in sitemap
- ✅ Blog has good volume (360 articles is substantial)

### Gaps Identified
1. **No product schema validation possible via API** — need to check if products have AggregateRating/Offer schema
2. **Blog cadence declining** — ~18 articles in 2026 vs higher cadence in 2024-2025
3. **Collection descriptions likely empty** — Shopify collections often lack SEO-optimized descriptions
4. **Size chart pages create thin content risk** — 40+ size charts with minimal text
5. **No blog categories/tags** — like Rank Ray, all posts under two blogs without topical structure

## Recommended Actions
| Priority | Action | Notes |
|----------|--------|-------|
| P1 | Verify product schema markup (Price, Availability, AggregateRating) | Shopify default includes some; verify via testing tool |
| P2 | Add curated descriptions to top 20 collections | Boosts collection page ranking |
| P3 | Increase blog cadence to 2-4 posts/month | Target buyer-intent topics |
| P4 | Consolidate thin size chart pages via noindex or merge | 40+ size charts = crawl waste |
| P5 | Add collection-level FAQ schema | High impact for long-tail queries |

## Summary
**Site health: Strong.** Shopify automation handles product/collection freshness well. 2,149 products with images is solid. Main opportunities are: collection SEO descriptions, blog cadence improvement, and schema enrichment.
