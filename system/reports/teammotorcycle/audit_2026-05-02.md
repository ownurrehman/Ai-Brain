## 2. Technical Issues

### 2.1 [CRITICAL] Missing Meta Description on Homepage
- **Evidence:** `curl -s https://www.teammotorcycle.com/ | grep 'meta name="description"'` returned empty. The homepage has NO meta description tag.
- **Impact:** Search engines will auto-generate snippets, often pulling irrelevant text. Direct CTR loss.
- **Fix:** Add a meta description (under 160 characters) via Shopify Admin → Online Store → Preferences. Suggested: "Buy motorcycle gear online at Team Motorcycle. Shop helmets, jackets, gloves, boots & luggage. Fast free shipping & free first exchange on all orders."
- **Can Autofix?** No (requires Shopify admin access).

### 2.2 [CRITICAL] Missing Meta Description on Collection Pages
- **Evidence:** The Motorcycle Helmets collection page (and likely others) relies on auto-generated descriptions. No unique meta descriptions found.
- **Impact:** All 200+ collection pages have duplicate/non-existent meta descriptions. This is the highest-impact fix opportunity.
- **Fix:** Add unique meta descriptions for top 20-30 collection pages at minimum. Each should include the collection's primary keyword, a value proposition, and "Team Motorcycle" brand.
- **Can Autofix?** No (requires Shopify admin or API access).

### 2.3 [HIGH] Non-Canonical Domain Redirect (team → www)
- **Evidence:** `https://teammotorcycle.com/` issues a 301 redirect to `https://www.teammotorcycle.com/`. The redirect uses `x-redirect-reason: canonical_host_redirection`. This is correct behavior.
- **Status:** Working correctly. No fix needed.
- **Concern:** Verify ALL internal links use the `www` version. No mixed internal linking detected from sitemap review.

### 2.4 [MEDIUM] 404 on Malformed Sitemap Sub-URLs
- **Evidence:** The sitemap index references sub-sitemaps with query parameters like `?from=141697188159&to=158788518207`. These sub-sitemaps load correctly only with proper URL encoding. Without encoding, they return 404.
- **Impact:** Low for users, but could cause issues for some crawlers that don't handle query-parameter sitemaps well.
- **Fix:** This is standard Shopify behavior. Consider submitting the main sitemap.xml to Google Search Console directly.
- **Can Autofix?** N/A (Shopify default).

### 2.5 [MEDIUM] No Breadcrumb Schema
- **Evidence:** No JSON-LD breadcrumb markup detected on collection or product pages.
- **Impact:** Missing rich result opportunity in SERPs. Breadcrumbs help search engines understand site hierarchy.
- **Fix:** Shopify themes typically support this natively. Check if the current theme (v32) has breadcrumb schema enabled. Enable in theme settings.
- **Can Autofix?** No (requires theme configuration).

### 2.6 [LOW] AhrefsBot Crawl Delay Set
- **Evidence:** `robots.txt` has `Crawl-delay: 10` for AhrefsBot and AhrefsSiteAudit.
- **Impact:** Slows down SEO audits but doesn't affect Google. Reasonable for resource management.
- **Status:** Acceptable. No action needed.

## 3. On-Page SEO Issues

### 3.1 [CRITICAL] H1 Tag is an SEO Block Heading, Not a Product-Focused H1
- **Evidence:** Homepage H1: `"Shop Motorcycle Gear From Team Motorcycle"` - wrapped in a custom CSS class `tm-seo-block__heading`. This is generic and doesn't target the primary commercial keyword "motorcycle gear."
- **Suggested H1:** "Buy Motorcycle Gear Online — Helmets, Jackets & Riding Equipment"
- **Can Autofix?** No (requires theme editing).

### 3.2 [HIGH] Collection Pages Lack Unique H1 Content
- **Evidence:** Collection page titles are generic like "Motorcycle Helmets | Best Motorcycle Helmet | Team Motorcycle" which is acceptable, but the H1s on many collections are just the collection name with no differentiation.
- **Fix:** Add collection-specific descriptive H1s. Example for Motorcycle Helmets: "Motorcycle Helmets for Every Rider — Full Face, Modular & More"
- **Can Autofix?** No.

### 3.3 [HIGH] Image Alt Text Issues on Homepage
- **Evidence:** The homepage product grid and category images on the homepage are loaded via JavaScript/lazy-loading. While product pages themselves have alt text from product titles, the homepage's category section images (Leather Gloves, Luggage, Leather Jackets, etc.) appear to have minimal or repetitive alt attributes.
- **Fix:** Ensure all homepage category/section images have unique, keyword-rich alt text. Example: "Leather Gloves" → "Men's Leather Motorcycle Riding Gloves - Team Motorcycle"
- **Can Autofix?** No.

### 3.4 [HIGH] Thin Content on Size Chart Pages
- **Evidence:** The pages sitemap contains 40+ size chart pages (e.g., `/pages/hjc-helmets-size-chart`, `/pages/afx-size-chart`, etc.). These are necessary for UX but are indexed with minimal content.
- **Impact:** These 40+ pages are essentially thin/duplicate content. They dilute crawl budget.
- **Fix:** Add `noindex, follow` to all size chart pages OR consolidate into a single interactive size guide tool/page.
- **Can Autofix?** No (requires theme code or Shopify admin).

### 3.5 [MEDIUM] Duplicate Contact Pages
- **Evidence:** Sitemap contains both `/pages/contact` and `/pages/contact-us`. This is a duplicate content issue.
- **Fix:** 301 redirect one to the other. Recommended: redirect `/pages/contact-us` → `/pages/contact`.
- **Can Autofix?** No (requires Shopify admin URL redirect).

### 3.6 [MEDIUM] Sale/Event Collection Pages Without Products
- **Evidence:** Several seasonal sale collections exist in the sitemap (e.g., Easter Sale, Halloween Sale, Veterans Day Sale) that may be empty or have very few products during off-season periods.
- **Impact:** Thin page content when not during the relevant season.
- **Fix:** Add "noindex" to off-season sale collections or keep them populated with general sale items year-round.
- **Can Autofix?** No.

### 3.7 [LOW] Open Graph Tags Present but Generic
- **Evidence:** OG tags exist on homepage but use generic descriptions across many pages (e.g., `og:description` content="Buy Motorcycle Gear Online with Reviews and Guides from Team Motorcycle and get Fast Free Shipping and Free First Exchange."). This is actually decent.
- **Status:** Acceptable. The OG image (`tmmSocialShareLogo.jpg`, 1200x628) is properly configured.

### 3.8 [LOW] Twitter Card Uses `summary` Not `summary_large_image`
- **Evidence:** `<meta name="twitter:card" content="summary">` - this displays a small thumbnail instead of a large image card.
- **Fix:** Change to `summary_large_image` for better social media visibility.
- **Can Autofix?** No (requires theme.liquid edit).

## 4. Blog/Content Issues

### 4.1 [HIGH] Blog Posts Use Outdated Years
- **Evidence:** Multiple blog posts reference "2024" in titles (e.g., "Best Cold Weather Motorcycle Jackets 2024", "The Best Leather Motorcycle Jackets Under $500") even though we're in 2026.
- **Impact:** Signals outdated content to both users and search engines. Freshness is a ranking factor.
- **Fix:** Update blog post titles to "2026" or remove the year entirely for evergreen content. Update content if products have changed.
- **Can Autofix?** No (requires Shopify blog admin).

### 4.2 [MEDIUM] Blog Image Alt Text Inconsistencies
- **Evidence:** Some blog image captions in the sitemap show `image:caption` with "thumnail-image-..." prefixes (literal typo: "thumnail" instead of "thumbnail"), suggesting auto-generated captions.
- **Impact:** Poor image SEO for blog content. These images could rank in Google Images.
- **Fix:** Manually set proper alt text on all blog post featured images.
- **Can Autofix?** No.

### 4.3 [LOW] News Blog Section Underutilized
- **Evidence:** The News blog (`/blogs/news`) has only ~15 posts, most from 2015-2016 (old republished content from a prior site). The Guides blog (`/blogs/guides`) has 120+ posts and is actively maintained.
- **Status:** Low priority but the News blog posts are extremely old. Consider archiving or updating them.
