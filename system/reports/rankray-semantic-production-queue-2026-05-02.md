## 7. QUALITY GATES (Per Post)

Every post must pass this checklist before being considered complete:

### Content Quality
- [ ] No em dashes or en dashes
- [ ] No repeated words consecutively
- [ ] No duplicate paragraphs or concepts
- [ ] No H1 in body content (WordPress generates H1 from title)
- [ ] Body starts with `<p>` or `<h2>`, never `<h1>`
- [ ] Active voice dominates (80%+)
- [ ] Word count meets target (2,000+ minimum for all tiers)

### Semantic SEO
- [ ] Primary keyword in H1
- [ ] Primary keyword in first 100 words
- [ ] Primary keyword in at least one H2
- [ ] 7 of 9 semantic frames covered
- [ ] LSI keywords woven naturally (8-12 per 1000 words)

### On-Page SEO
- [ ] Meta title: <60 characters, includes primary keyword + brand
- [ ] Meta description: <160 characters, includes keyword + LSI + Brand name
- [ ] Yoast focus keyphrase set
- [ ] Correct category/categories assigned

### Internal Links
- [ ] 8-12 internal links for 2,500+ word articles
- [ ] No duplicate internal links (same page linked twice)
- [ ] Links verified against sitemap
- [ ] "Rank Ray" anchor text → homepage ONLY
- [ ] Link distribution: 40% services, 40% blogs, 20% pillar

### Media
- [ ] 1 featured image only — no images under H2 sections
- [ ] Image uploaded to WordPress Media Library (no hotlinking)
- [ ] Descriptive filename and alt text with keyword variation
- [ ] Max file size: 100KB

### Publishing
- [ ] Status: Draft (never publish without user approval)
- [ ] Clean slug, no "-draft" suffix
- [ ] Yoast analysis verified
