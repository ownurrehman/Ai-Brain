# Self-Audit Protocol (Mandatory Verification)

This protocol must be executed before delivering ANY high-value output (Content, Code, or Strategy).

## 1. Compliance Check
- [ ] **Rules Alignment:** Does the output follow the site-specific rules in `mastersheet.md`?
- [ ] **Banned Phrases:** Does the content contain any "Agentisms" (e.g., "In the rapidly evolving landscape," "delve," "unlocking")?
- [ ] **Semantic SEO:** Are the entities and intent aligned with the `semantic-seo-writer.md` framework?

## 2. Technical Integrity
- [ ] **Link Verification:** Are all internal/external links functional and relevant?
- [ ] **Technical Rules:** NO `<h1>` tags in body content (H2 is the max allowed).
- [ ] **AI Footprint:** NO em-dashes (—) or en-dashes (–). Use hyphens or colons.
- [ ] **Markdown Hygiene:** No broken formatting, correct header hierarchy (H2 -> H3 -> H4).
- [ ] **Credential Safety:** No API keys or passwords exposed in the output.

## 3. SEO Quality (Koray's Framework)
- [ ] **Topical Coverage:** Does the response address the primary entity and its properties?
- [ ] **Information Density:** Is the word-to-value ratio optimized? (No fluff).
- [ ] **Instruction Following:** Did I miss any specific constraint mentioned in the prompt?

## 4. Final Polish
- [ ] **Tone Check:** Is the voice consistent with the project's persona?
- [ ] **Accuracy:** Are facts verified?
- [ ] **Formatting:** Is the layout readable and premium?

**Failure to pass this audit requires a full rewrite of the affected section.**
