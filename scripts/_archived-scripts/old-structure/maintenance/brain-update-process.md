# Brain Update Process

## Add only when justified

Create or expand a file only if it does one of these:

- reduces repeat prompting,
- prevents a recurring mistake,
- captures a stable workflow, or
- improves routing enough to save future context.

## Prefer editing over adding

- Update an existing file before creating a new one.
- Merge overlapping guidance quickly.
- Delete stale or duplicate content instead of archiving it forever.

## Keep files lean

- Start with a short summary.
- Keep instructions operational.
- Move detail into a reference only when it meaningfully reduces future token use.

## Review cadence

- Prune quarterly or after a large workflow change.
- Re-check `INDEX.md` whenever files are added, removed, or renamed.
- Tighten any file that becomes vague, repetitive, or rarely used.
