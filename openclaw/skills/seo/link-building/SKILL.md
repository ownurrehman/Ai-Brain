## Competitor Backlink Analysis

### Step 1: Identify Competitors

| Site Type | Competitor Examples |
|-----------|---------------------|
| **Tonic Physio (Local Clinic)** | Other physio clinics in Milton/Toronto, chiropractors, massage therapy clinics |
| **Khan LLP (Law Firm)** | Other personal injury lawyers in Oakville/Toronto, legal directories |
| **Team Motorcycle (E-commerce)** | Other motorcycle gear retailers, brand websites (Alpinestars, Dainese) |
| **Coinsfera (Crypto OTC)** | Other crypto OTC desks, crypto exchanges, Bitcoin ATM companies |
| **Rank Ray (SEO Agency)** | Other SEO agencies in target markets (Dubai, USA, Pakistan, Canada) |

### Step 2: Analyze Competitor Backlinks

**Tools (choose available):**
- Ahrefs (paid) — Most comprehensive
- Semrush (paid) — Good alternative
- Moz Link Explorer (freemium)
- Ubersuggest (freemium)
- Google Search Console (free, own site only)

**Data to Extract:**
```
- Source URL (where link is placed)
- Source Domain Authority (DA/DR)
- Link type (dofollow/nofollow)
- Anchor text
- Page title
- Content type (blog, directory, resource page, news)
- First seen date
```

### Step 3: Categorize Link Opportunities

| Category | Action | Priority |
|----------|--------|----------|
| Directories | Submit to same directories | High (quick win) |
| Guest Posts | Pitch similar topics | High (scalable) |
| Resource Pages | Request inclusion | Medium (low competition) |
| News/Media | Digital PR pitch | High (authority boost) |
| Forums/Communities | Participate authentically | Medium (long-term) |
| Broken Links | Offer replacement content | High (easy yes) |

## HARO (Help A Reporter Out) Automation

### What is HARO?

HARO connects journalists with expert sources. Respond to relevant queries → get quoted → earn high-authority backlinks.

**Alternative Services:**
- Qwoted
- SourceBottle
- Terkel
- Featured (by Content Harmony)

### HARO Query Monitoring

**Query Sources:**
- HARO emails (3x daily: 5am, 12pm, 5pm EST)
- Twitter: `@HARO` + keywords
- RSS feeds (if available)

**Query Filtering Criteria:**
```
✅ Relevant to your industry/expertise
✅ Your client is qualified to answer
✅ Deadline allows time for quality response
✅ Publication has high DA (50+)
❌ Too broad/generic (low chance of selection)
❌ Already answered by competitor
```

### HARO Response Template

```
Subject: Expert Source: [Query Topic] — [Your Name/Company]

Hi [Journalist Name],

I saw your HARO query about [topic] and I'm well-positioned to help.

[1-2 paragraph direct answer to the query, quotable, specific]

About me:
- [Relevant credential/experience]
- [Company/role]
- [Location if relevant]

I can provide:
- Additional quotes/data if needed
- High-res headshot
- Quick turnaround on follow-ups

Best,
[Name]
[Title]
[Company]
[Phone]
[Website]
```

## Guest Posting Outreach

### Step 1: Find Guest Post Opportunities

**Search Operators:**
```
"write for us" + [keyword]
"guest post" + [keyword]
"submit article" + [keyword]
"become a contributor" + [keyword]
inurl:write-for-us [keyword]
```

**Example Searches:**
- `"write for us" physiotherapy`
- `"guest post" personal injury lawyer`
- `"submit article" motorcycle gear`
- `"write for us" crypto`
- `"guest post" SEO marketing`

### Step 2: Vet Opportunities

| Criteria | Pass | Fail |
|----------|------|------|
| Domain Authority | 40+ | <30 |
| Organic Traffic | 10k+/month | <5k |
| Content Quality | Well-written, original | Thin, spun content |
| Link Placement | In-content, dofollow | Footer, sidebar, nofollow |
| Response Time | <1 week | >2 weeks |
| Guidelines Clear | Yes | No/vague |

### Step 3: Pitch Template

```
Subject: Guest Post Pitch: [Specific Topic Idea] for [Site Name]

Hi [Editor Name],

I've been reading [Site Name] for a while and loved your recent post on [specific article].

I'd like to contribute a guest post that would resonate with your audience:

**Topic:** [Specific, compelling title]

**Outline:**
- [Key point 1]
- [Key point 2]
- [Key point 3]
- [Unique angle/data/experience you bring]

**Why me:**
- [Relevant expertise/credential]
- [Previous publications (if any)]
- [Unique perspective or data]

The article would be [word count] words, original, and include [images/data/examples].

Would this be a good fit for [Site Name]?

Best,
[Name]
[Credentials]
[Website]
```

## Broken Link Building

### Step 1: Find Broken Links

**Tools:**
- Check My Links (Chrome extension)
- Ahrefs Site Audit
- Screaming Frog
- Broken Link Checker (online tool)

**Target Pages:**
- Resource pages in your niche
- Industry blog roundups
- "Best X" listicles
- Educational/.edu pages

### Step 2: Verify Broken Link

```
1. Check HTTP status (should be 404/410)
2. Archive.org — what was the content?
3. Can you create something better?
```

### Step 3: Outreach Template

```
Subject: Broken Link on [Page Title]

Hi [Name],

I was reading your excellent resource on [topic] and noticed a broken link:

**Broken Link:** [URL]
**Anchor Text:** [anchor]
**Located On:** [page URL]

I recently published a comprehensive guide on the same topic that might be a good replacement:

**My Resource:** [your URL]
**What it covers:** [brief description]

Either way, thought you'd want to know about the broken link!

Best,
[Name]
```

**Tools:**

**Search Queries:**

```
Subject: Quick Question About Your [Article Title]

Hi [Name],

Thanks for mentioning [Brand/Product] in your recent article!

I noticed the mention isn't linked — would you mind adding a link to our site?

**Mention Location:** [URL + context]
**Suggested Link:** [your URL]

Happy to return the favor with a mention on our end!

Best,
[Name]
```
