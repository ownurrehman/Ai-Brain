# LSI Keywords by Category for Enigma

## What are LSI Keywords?

LSI (Latent Semantic Indexing) keywords are terms semantically related to a primary keyword. They help search engines understand content context and improve rankings.

## Using This Reference

- Include 1-2 LSI terms in every meta description
- Sprinkle LSI terms naturally throughout content
- Use in H2/H3 subheadings where relevant

## Quick Selection Rule

**For any keyword, find an LSI term that:**
1. Adds context (what type, where, how)
2. Sounds natural when combined
3. Your audience actually searches for

**Example combinations:**
- "SEO" + "organic traffic"
- "physiotherapy" + "pain management"
- "crypto exchange" + "fiat to crypto"
