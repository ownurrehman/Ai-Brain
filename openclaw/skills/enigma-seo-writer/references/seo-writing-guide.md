# SEO Writing Guide for Enigma

## Writing for Search Intent

Search intent has 4 primary types. Match your content to the intent:

| Intent Type | Example Query | Content Approach |
|-------------|---------------|------------------|
| Informational | "what is seo" | Educational, comprehensive, define clearly |
| Commercial | "best seo agency" | Comparison, reviews, lead generation focus |
| Transactional | "hire seo agency" | Service pages, pricing, CTA-focused |
| Navigational | "rank ray seo" | Brand-specific, location/contact info |

## Content Structure Standards

### Pillar Page Structure
1. Introduction (150-200 words)
2. What is [Topic] (200-300 words)
3. Why [Topic] Matters (200-300 words)
4. Key Benefits (bulleted list)
5. How to Implement [Topic] (500-800 words)
6. Common Mistakes (200-300 words)
7. FAQ Section (3-5 questions)
8. Conclusion + CTA (100-150 words)

### Listicle Structure
1. Catchy intro hook
2. Anticipated benefit statement
3. Table of contents
4. 5-15 items with:
   - H2 for each item
   - 100-150 words per item
   - Practical tip or example
5. Summary/which to choose
6. CTA

## Keyword Placement Rules

- **Title Tag**: Primary keyword within first 55 characters
- **H1**: Primary keyword at the beginning
- **First 100 words**: Primary keyword naturally included
- **H2s**: Include keyword variants where natural
- **Body**: Keyword density 1-2% (natural, no stuffing)
- **Image alt text**: Include keyword if relevant
- **URL**: Include primary keyword, hyphen-separated

## Readability Standards

**Target Flesch-Kincaid Grade Level:** 8-12 for B2B, 6-8 for B2C

**Best practices:**
- Sentence length: Average 15-20 words
- Paragraph length: 2-3 sentences max
- Bullet points: Use for lists of 3+ items
- Bold key takeaways: 1-2 per section
- Transition words: Use to connect ideas

## Internal Linking Strategy

**Priority for Link Placement:**
1. Contextual links within body text
2. Related posts section (end of article)
3. Navigation breadcrumbs

**Anchor Text Rules:**
- Descriptive ("SEO content writing guide" not "click here")
- Natural in sentence flow
- Vary anchor text for same target across different pages
- Never use exact-match anchor text for >10% of links

## SERP Feature Optimization

**Featured Snippets:**
- Use "What is", "How to", "Why does" in H2s
- Provide concise 40-60 word answers
- Use numbered lists for steps
- Use tables for comparisons

**People Also Ask:**
- Answer PAA questions in FAQ sections
- Use question format in H3s
- Provide direct 50-word answers

**Image Pack:**
- Use descriptive file names
- Include alt text with keywords
- Optimize file size (<100KB)
- Use original images when possible
