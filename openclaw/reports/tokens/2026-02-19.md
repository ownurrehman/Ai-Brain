# Token-Saving Tactic: Prompt Compression

## Technique: Structured Delimiter-Based Compression

Wrap variable content in XML/JSON tags and reference by tag ID in subsequent prompts instead of repeating full context.

## Implementation

```
First call: "Process this dataset: <data id='A'>[full content]</data>"
Follow-up:  "Summarize <data id='A'> by category"
```

## Impact

- **~40-60% token reduction** on multi-turn conversations
- Works across Claude, Gemini, OpenAI APIs
- Zero code changes; pure prompt engineering
