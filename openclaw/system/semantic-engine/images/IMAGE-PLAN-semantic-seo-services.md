## Image SEO Best Practices (Rank Ray Standard)

### Filenames
- ✅ Keyword-based, descriptive
- ✅ Lowercase with hyphens
- ✅ NO "featured image" in filename
- ✅ Include brand name for featured image
- ✅ Landscape orientation preferred

### Alt Text
- ✅ Mandatory for every image
- ✅ Descriptive with natural keyword variation
- ✅ NO keyword stuffing
- ✅ 100-150 characters optimal
- ✅ Describe what image shows, not just keywords

### Technical
- ✅ WebP format preferred (or optimized JPG)
- ✅ Max 150KB per image
- ✅ Proper dimensions for placement
- ✅ Compressed for web performance

### Upload Process
1. Check existing media library for duplicates
2. Download from free source (Unsplash/Pexels)
3. Rename with keyword-based filename
4. Optimize/compress if needed
5. Upload via WordPress REST API
6. Set alt text immediately
7. Record in local media index
