# Rank Ray Media Rules

1. Use clean keyword-based filenames only.
2. Never use "featured image" in filename or alt text.
3. Alt text is mandatory for every uploaded image.
4. Prefer landscape images for Rank Ray SEO/city pages unless layout requires otherwise.
5. Before upload, search for existing suitable assets by topic/slug.
6. Before upload, run duplicate check against local media index.
7. Reuse suitable existing assets when possible.
8. Log every new upload into the media index after successful upload.
