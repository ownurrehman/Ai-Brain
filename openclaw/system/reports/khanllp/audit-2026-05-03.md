## 1. CRITICAL ISSUES

### 1.1 WWW → Non-WWW Redirect Missing (Critical)
- `https://www.khanllp.com/` returns **HTTP 200** without redirecting to `https://khanllp.com/`
- Both www and non-www versions serve identical content with same canonical pointing to non-www
- **Impact:** Duplicate content risk. Search engines may index both versions. Link equity split.
- **Fix:** Add 301 redirect from `www.khanllp.com` to `https://khanllp.com/` in Apache `.htaccess`:
  ```
  RewriteEngine On
  RewriteCond %{HTTP_HOST} ^www\.khanllp\.com [NC]
  RewriteRule ^(.*)$ https://khanllp.com/$1 [L,R=301]
  ```

### 1.2 Schema Markup is Inadequate (Critical)
- Homepage only has `@type: WebPage` schema - **no LocalBusiness, LegalService, Organization, or Attorney schema**
- LocalBusiness/LegalService schema is essential for a law firm for local SEO and Google Maps visibility
- Missing: NAP (Name, Address, Phone), opening hours, service areas, reviews/ratings, social profiles
- Service pages (e.g., real-estate-lawyer-toronto) have NO structured data at all
- FAQ schema appears to be present (4 Question references on service page) but not properly marked up in JSON-LD
- **Fix:** Implement JSON-LD schema:
  - Homepage: `LocalBusiness` + `Organization` with all locations
  - Service pages: `LegalService` with areaServed, serviceType
  - Blog posts: `Article` + `BreadcrumbList`
  - FAQ sections: `FAQPage` schema

### 2.2 Missing Security Headers (High)
- No `Strict-Transport-Security` (HSTS)
- No `X-Content-Type-Options`
- No `X-Frame-Options`
- No `Content-Security-Policy`
- No `Referrer-Policy`
- No `Permissions-Policy`
- **Impact:** Security vulnerability; minor negative SEO signal
- **Fix:** Add to Apache config or .htaccess:
  ```
  Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains"
  Header always set X-Content-Type-Options "nosniff"
  Header always set X-Frame-Options "DENY"
  Header always set Referrer-Policy "strict-origin-when-cross-origin"
  ```

### 2.3 Homepage Meta Keywords Tag is Empty

- **Impact:** Minor. Google ignores keywords meta but having an empty tag is sloppy
- **Fix:** Either populate meaningfully or remove the tag entirely

### 2.4 Empty Twitter Description
