## How to Create New Pages:

1. Go to **Pages → Add New**
2. Enter **Page Title**
3. Paste content from the content map file (format H1, H2, paragraphs, FAQs)
4. Set **Slug** (URL) in right sidebar under "URL" or "Permalink"
5. Set **Featured Image** (use Image ID to search in Media Library)
6. Insert content images where marked `[IMAGE: ...]`
7. Scroll to **Yoast SEO** section
8. Enter **Focus Keyphrase** and **Meta Description**
9. Verify **Green Yoast status**
10. Click **Publish**

## Image Assignment in WordPress:

To assign images by ID:

2. In Media Library, use search or filter
3. Or directly enter Image ID in URL: `https://tonicphysio.com/wp-admin/upload.php?mode=list`
4. Find image by ID and click "Use as featured image"
