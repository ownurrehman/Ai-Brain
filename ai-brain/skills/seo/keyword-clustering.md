# Keyword Clustering

## Cluster by

- Shared intent.
- Shared page type.
- Similar SERP overlap.
- Similar stage in the user journey.

## Split when

- One term wants a product or category page and another wants an article.
- One term is local and another is general.
- One term is comparison-focused and another is how-to focused.

## Output shape

- Cluster name.
- Primary term.
- Supporting terms.
- Recommended page type.
- Notes on cannibalization risk.
