# SEO

## Focus order

1. Search intent fit.
2. Page type fit.
3. Content depth versus SERP expectations.
4. Internal linking and topical support.
5. On-page clarity.

## Practical rules

- One page should serve one dominant intent.
- Merge terms that share the same ranking page type and user need.
- Separate terms when intent, funnel stage, or page type changes materially.
- Prefer updating a relevant page before creating a new one.

## Useful outputs

- Primary keyword or topic.
- Supporting terms.
- Recommended page type.
- Reason the page can win.
- Next SEO action.
