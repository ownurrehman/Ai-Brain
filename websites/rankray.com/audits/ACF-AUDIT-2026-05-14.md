## Fix Workflow (from Sheet to Site)

1. **Open** `Audit - Summary` → Sort "Needs Work?" = YES → pick page
2. **Open** `Audit - Service Detail` or `Audit - Location Detail` → Filter by Page ID
3. **Write** content for each EMPTY/THIN field
4. **Update** "Fix Status" column in Sheet with "CONTENT_READY"
5. **Push** content to WordPress via REST API (chunked, 5-12 fields/chunk)
6. **Verify** frontend renders correctly
7. **Update** Sheet "Fix Status" → "DONE" → mark "Needs Work?" = NO

## Lessons Learned

1. **Never hardcode field lists** — always read from source CSV
2. **Image fields** (image_for_h2_para_*) should be excluded from "empty" count
3. **Tool pages** have no ACF — skip them
4. **Location pages** use a completely different ACF template (99 fields vs 64)
5. **Dynamic field names** (meta_H2, meta_H2_Paragraph_1) have inconsistent casing
