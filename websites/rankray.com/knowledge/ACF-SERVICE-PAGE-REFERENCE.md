### Format Rules (P0)
1. **NO \u003cp\u003e tags on simple text fields.** Elementor already wraps text. Use PLAIN TEXT for:
   - services_1-6_paragraph
   - answer_1-10
   - why_us_box_1-6_paragraph
   - h3_portfolio_paragraph_before_3_boxes
   - before_services_paragraph
   - why_us_h3_paragraph
2. **\u003cp\u003e tags ONLY when a field contains a custom heading** (like \u003ch3\u003e in h2_paragraph_2/3). NEVER \u003cbr/\u003e\u003cbr/\u003e.
3. **H2:** Sell pattern, not "What Is..."
4. **H3:** First H3 goes in h2_paragraph_2, SECOND H3 goes in h2_paragraph_3. Both fields must have content.
4a. **NEVER leave h2_paragraph_3 empty** — creates broken frontend with empty section
5. **No links in h1_paragraph** (above the fold)
6. **Internal links:** Natural, contextual, after the fold only
7. **Portfolio area:** Bold heading + problem + solution + strategy + scale + CTA
