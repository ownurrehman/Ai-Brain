## WordPress REST API Strategy

For each post:
1. GET current content via `/wp-json/wp/v2/posts/<id>`
2. Parse content for existing links
3. Insert contextual links at natural positions
4. PUT updated content back
5. Verify on frontend

**Rate limiting:** 5 posts per minute to avoid server strain
**Batch size:** 20 posts per run
**Anchor text rules:**
- Exact match: max 20% of links
- Partial match: 50%
- Natural/contextual: 30%
- No "click here" or "read more"
