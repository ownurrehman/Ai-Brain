The 690 site images were **not** stored locally before — they only lived on the live WordPress server (`wp-content/uploads/`). This folder was generated by downloading from the live URLs in `csvs/justccell-media-inventory.csv` and saving each file with its SEO `suggested_filename`.

## Folders

| Path | Contents |
|------|----------|
| `in-use/` | **168 images** actually used on the live site — upload these first |
| `unused/` | Remaining library items (orphans, old imports, duplicates) |
| `manifest.json` | Maps old attachment ID → local file → alt text → usage |

## Upload workflow

1. **Justccell → Media replace** → click **Mark current library as legacy**
2. **Media → Add Media File** → upload everything from `in-use/` (filenames are already correct)
3. **Justccell → Media replace** → **Reconnect matched uploads**
4. Verify live site → **Delete replaced legacy files**
5. Optionally upload `unused/` if you want a clean full library

## Regenerate

```bash
python3 scripts/download-media-replace.py --in-use-only   # site images only
python3 scripts/download-media-replace.py                 # all 690
```
