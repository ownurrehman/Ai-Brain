# justCCELL Features

WordPress plugin for [justccell.com](https://justccell.com/) — **Author: Rank Ray**

Requires the **Justccell** theme (`justccell-theme`) for templates, CSS/JS, and ACF Local JSON.

## What this plugin owns

- wp-admin **Justccell** menu (Overview, Storefront, Header, Forms, Laser Engraving, Elite Cross-sell, Quote leads)
- WooCommerce catalog, tier pricing, cart AJAX, checkout modernization
- Laser engraving engine, inquiry / quote leads CPT
- ACF integration hooks (JSON files remain in the theme `acf-json/` folder)
- Geo / storefront cookies, WPML lock, REST prelaunch gate, coming soon logic
- Storefront asset enqueue (URLs point at the active theme)
