## 1. Website Technical Audit (Current State)

### Critical Issues Found

islamicft.com is built as a **single-page application (SPA)** using Vite + Bootstrap 5.3. This architecture means the website serves an empty HTML shell (1,755 bytes) and loads all content via JavaScript. **Google can barely see any content on the site.**

| Issue | Impact | Severity |
|-------|--------|----------|
| No robots.txt | Search engines crawl blindly | Critical |
| No sitemap.xml | Google cannot discover pages | Critical |
| No meta descriptions | No search result snippets | Critical |
| No SSR/SSG — Google sees only 3 words of content | Site effectively invisible to search engines | Critical |
| No canonical tags | Duplicate content risk | High |
| No Open Graph / social media tags | Poor social sharing appearance | Medium |
| No structured data (JSON-LD) | No rich results in Google | High |
| 57 routes all serve the same HTML shell | Every page looks identical to Google | Critical |
| No image alt text | Image SEO completely missing | Medium |
| CDN-loaded Bootstrap + icons (3 external CDNs) | Slow page load | Medium |

### What's Working
- HTTPS enabled
- Google Analytics installed (GA4: G-NQKX5EBFVT)
- Clean URL structure with 57 routes
- Mobile responsive (Bootstrap 5)
- Content exists in the app (Islamic finance data, market analysis, news, publications, scholars, events, Cambridge IFA services)

## 2. Proposed SEO Strategy

### Phase 1 — Technical Foundation (Month 1)
- Fix robots.txt and sitemap.xml generation
- Add meta titles + descriptions to all 57 routes
- Implement prerendering or SSG for critical pages (30+ public pages)
- Add canonical tags, Open Graph tags, and structured data
- Optimize CDN resources (reduce external dependencies)
- Fix image alt text across all assets
- Submit sitemap to Google Search Console
- Set up Google Search Console monitoring

### Phase 2 — On-Page SEO (Months 1–2)
- Keyword research for Islamic finance niche (PK + global Muslim markets)
- Optimize page titles and headings for target keywords
- Internal linking structure across 57 pages
- Content optimization for key pages: /ift-app, /markets, /analysis, /country-data
- Schema markup: Organization, WebSite, NewsArticle, FinancialService
- Fix image optimization (WebP format, lazy loading)

### Phase 3 — Content SEO (Month 2 onwards)
- Blog setup with 4-8 articles/month targeting Islamic finance keywords
- Topic clusters: Islamic banking, halal investing, shariah-compliant finance, Islamic capital markets
- Country-data page optimization (regional Islamic finance reports)
- Cambridge IFA service pages optimization
- Newsletter signup optimization

### Phase 4 — Link Building + Authority (Month 3 onwards)
- Islamic finance directory submissions
- Guest posting on Islamic finance blogs
- Press release distribution
- Local citations for Pakistani market
