## 🚀 Core Mandates
1. **No Blind Extra Custom Coding:** Rely on native WordPress core & WooCommerce first before writing custom code.
2. **100% Backend Content Editability:** Every front-end headline, paragraph, CTA button, link, and image must be editable via native WP/Woo fields or mapped ACF Pro fields.
3. **Minimalist & Compact ACF UI:** ACF fields must never bloat the backend edit screen. Keep textareas short (`rows: 2`), use tabs, and table-layout repeaters.
4. **Pixel-to-Pixel Abstrax Tech Clone:** Replicate visual beauty and scientific botanical styling while maintaining a **strict zero public footprint** of the source domain.
5. **Cross-Site 48h Free Delivery (Justccell → Elite, live 2026-09-04):** Plugin `justccell-coupon-bridge`. Hostinger `u984013785`. Reverse not built.
