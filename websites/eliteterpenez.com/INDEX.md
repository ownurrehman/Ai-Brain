## ⚡ Core Client Policies & Highlights
1. **No Blind Extra Custom Coding:** Rely on native WordPress core and WooCommerce first.
2. **100% Backend Content Editability:** Every heading, paragraph, button text/link, and image must be editable via native WP/Woo fields or compact ACF Pro fields.
3. **Minimalist ACF UI:** Compact textareas (`rows: 2`), table-layout repeaters, tabs organization, and attachment ID returns. No vertical screen wasting.
4. **Visual Reference Clone:** Pixel-to-pixel frontend matching of `https://abstraxtech.com/` with absolute **Zero Public Footprint** of the source domain.
5. **Cross-Store Synergy:** 48-hour free delivery coupon integration with `justccell.com`.
