# Lessons Learned

| Pattern | Reusable lesson |
| --- | --- |
| Routing | Most tasks need one skill and one reference, not full-brain loading. |
| Writing | Clear structure usually beats extra word count. |
| SEO | Mixed intent is a frequent cause of weak page targeting. |
| Shipping | Smaller verified slices finish faster than broad partial changes. |
| Refactoring | Combining cleanup with behavior change hides regressions. |
