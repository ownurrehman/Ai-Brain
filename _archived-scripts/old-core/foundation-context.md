# Foundation Context

## Primary priorities

- High signal over high volume.
- Reuse over recollection.
- Fast routing over full documentation.
- Human maintainability over clever structure.
- Small context cost over exhaustive prose.

## Default assumptions

- Most tasks need one skill and one or two references, not a full library.
- The assistant is already competent; the brain should add only missing local judgment.
- A shorter file that changes behavior is more valuable than a longer file that explains it.

## What good looks like

- Clear trigger conditions.
- Minimal repeated wording.
- References separated from manifests.
- Files that remain useful across many tasks.
